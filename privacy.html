Privacy Policy — yt-uploader

Last updated: 15 October 2026

This policy describes how yt-uploader, a personal command-line application used by its owner to manage his own YouTube channels, handles Google user data.

1. What data the application accesses

With the account holder's explicit consent, the application accesses only data belonging to that same account:

  • YouTube account and channel data (youtube.upload, youtube, youtube.force-ssl): the channels the account owns, their videos, metadata, playlists and live streams — to upload videos, publish live streams and edit that metadata.
  • YouTube Analytics data (yt-analytics.readonly): view counts, watch time and other performance reports for the account's own channels.
  • OAuth credentials: an access token and a refresh token issued by Google, plus the OAuth client identifier.

The application does not access email, calendars, contacts, files, Google Drive, or any data belonging to other Google users.

2. How the data is used

Accessed data is used solely to perform the actions the account holder requests: uploading content, publishing live streams, editing his own channel metadata, and displaying reports about his own channels. No data is used for advertising, profiling, or training machine-learning models.

3. Where the data is stored

Everything stays on the account holder's own computer, in local configuration files:

  • OAuth tokens are stored in local files readable only by the account holder's operating-system user.
  • Analytics results and video metadata downloaded from the API are cached in local files on the same machine.

There is no server, no database, and no cloud storage operated for this application. No Google user data is transmitted to any third party, and no Google user data is sold or shared.

4. Retention and deletion

Tokens and cached data remain on the owner's machine until deleted. The account holder can revoke this application's access at any time at myaccount.google.com/permissions; the application then loses all access to the Google Account. Deleting the local token files removes the remaining credentials from the machine.

5. Limited Use

Data obtained through Google APIs is used only to provide the features described above. Its use complies with the Google API Services User Data Policy, including the Limited Use requirements.

6. Sharing

No Google user data is shared with third parties, except when required by law. Aggregate video statistics are visible on YouTube itself to the same extent as any other public YouTube video.

7. Contact

Questions about this policy or about the application's handling of data can be raised at github.com/disalvo/yt-uploader/issues.
