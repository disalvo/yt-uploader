# yt-uploader

Branding and legal pages for `yt-uploader`, a personal single-user command-line client for the
YouTube Data API.

- Homepage: https://disalvo.github.io/yt-uploader/
- Privacy policy: https://disalvo.github.io/yt-uploader/privacy.html

These pages exist so that the Google OAuth consent screen for this application can be published to
production (Google requires a valid app name, support email, homepage URL and privacy policy URL for
an external app). The application itself is private and has no users other than its owner.
